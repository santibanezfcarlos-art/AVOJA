Consulta de bonos Fonasa

Adjunta el bono para reconocer nombre, RUT y folio. El sistema consultará Bono Web mediante Decodo y, si encuentra la opción Activar, permitirá generar un enlace privado de agendamiento. No activa bonos.

1. Cargar comprobante

Los datos se extraen del PDF sin almacenar una copia del documento. Se valida el prestador y el código de psicoterapia.

2. Bono reconocido

Comprobaremos si aparece «Activar».

3. Enlace para agendamiento

Fonasa encontró el bono y mostró Activar. El enlace permite que la persona seleccione fecha y hora disponible e ingrese su propio correo.

La aparición del botón no equivale a una activación ni a una transferencia. El registro de hora quedará como solicitud pendiente hasta la confirmación en Google Calendar.
