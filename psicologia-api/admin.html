Adjunta el bono y verifica sus datos en Fonasa. Luego pulsa Activar bono en el historial. Cuando Fonasa confirme la activación, podrás generar el enlace privado para que el paciente elija su horario.

1. Cargar comprobante

2. Bono reconocido

3. Enlace para agendamiento

Fonasa confirmó que el bono está activado. El enlace permite que la persona seleccione fecha y hora disponible e ingrese su propio correo.

Orden del proceso: verificar el bono → activar en Fonasa → generar el enlace → seleccionar horario → confirmar la cita en Google Calendar y enviar los correos PSC. Si una respuesta queda pendiente, usa «Revisar activación» para consultar el resultado.
