CONTROL DE VENTAS

Boletas e historial de compras

Previsualiza el formulario SII con una compra real o una compra de prueba, usando el agente local en tu computador. La emisión automática definitiva está pendiente de validación; también puedes registrar una boleta ya emitida manualmente.

Para preparar una boleta, mantén abierto el agente local. Tu sesión del SII permanece en tu computador. Después pulsa Actualizar para consultar el resultado.

Registrar un folio aquí no emite una boleta ni informa al SII. El historial contiene datos privados: cierra todas las ventanas del navegador al terminar en un equipo compartido.
