# Fotos de los boxes

Sube aquí las fotos originales, sin datos de pacientes ni documentos visibles.

- Box 1: `box-1.jpg` o `box-1.png`
- Box 2: `box-2.jpg` o `box-2.png`
- Box 3: `box-3.jpg` o `box-3.png`

También se admite JPEG y WebP. Renombra el archivo antes de cargarlo sin cambiar su formato real. Usa preferentemente menos de 2 MB por foto y mantén una sola versión por box. El sitio muestra únicamente las fotos existentes; no utiliza fotografías inventadas. Las fotos son públicas.

En GitHub abre esta carpeta en la rama `valhalla-demo`, pulsa Add file → Upload files, arrastra la imagen renombrada y confirma Commit changes. Render la incluirá en el siguiente despliegue: las imágenes se copian desde el repositorio, no del disco temporal de la aplicación. Para actualizar la vista autónoma, ejecuta `python3 build_preview.py`.
